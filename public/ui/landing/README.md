# Landing artwork

The Landing screen loads these PNGs from this folder. Any file that is missing
is replaced by a drawn placeholder, so the game works before the art exists.

| File | What it is |
|---|---|
| `sky-16x9.png` | Daytime sky background for landscape screens |
| `sky-9x16.png` | Daytime sky background for portrait screens |
| `clouds.png` | Clouds and ribbons on a transparent background; it drifts sideways and repeats |
| `strawberry.png`, `ginza.png`, `chity.png`, `kusto.png`, `sugar.png` | Each character floating, cut out on a transparent background |

See "Higgsfield prompt pack → 4. Menu artwork layers" in docs/design.md.
