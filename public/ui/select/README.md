# Select artwork

The Character select screen paints this night forest behind the 3D stage.
If either file is missing, simple 3D trees stand in, so the game works before
the art exists.

| File | What it is |
|---|---|
| `forest-16x9.webp` | Night forest clearing for landscape screens |
| `forest-9x16.webp` | Night forest clearing for portrait screens |

Both need an empty clearing in the middle and lower part of the picture, where
the stage stands, and no stage or characters of their own.
